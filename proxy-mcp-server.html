How the pieces nest

  • MCP is a plug: Cursor is the client; GitHub and Notion are servers
  • A proxy sits in the middle so Cursor talks to one desk, not every kitchen
  • Real servers do the work; the proxy forwards, checks, and combines

What the neighbors do

  • Client: the app you chat with, sending MCP requests
  • Login: the keycard check before a tool may run
  • Tool: one action a real server can take, such as search

Why the proxy exists

  • One plug instead of wiring Cursor to every MCP server
  • Hide keys, block unsafe tools, and record what was asked
  • You keep talking to Cursor while servers behind the desk change
